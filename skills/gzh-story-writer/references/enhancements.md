# 可选增强片段

> **只在需要时读**。三种片段互不影响，都贴在主模板【写作要求】之后。
> - 四：想让文章更有传播力时
> - 五：用了选题卡（步骤 1.4）时
> - 六：字数超标需要精简时

## 四、通用增强片段

```
【爆款骨架增强】（可选。源自洞见式爆款文拆解，只借骨架、不借体例——
借选题/节奏/金句机制，换掉训诫体、掉书袋、口号收尾。）
1. 选题：踩中读者群体的高频处境或争议，给流行困惑一个"过来人的注脚"。
2. 钩子：开头 3 屏内给出具体场景或冲突（一个画面、一句台词、一个体面崩塌的瞬间）。
3. 故事支撑：每个情绪/论点段配一个具体故事或细节，不写超过一屏的抽象论述。
4. 金句：全篇至少一句可单独截图传播的话，放在段尾，不放在口号位。
   检验：单独截出来发朋友圈成立吗？不成立就重写。
   限频："不是…是…"类对仗判断句全篇最多 1 句；金句不必加粗，
   允许某篇 0–1 处加粗（防"每篇同位置押韵"的模板指纹）。
5. 标题：主句用熟悉的热词/处境短语 + 亲密场景钩子（"哪怕是家人""三十年""亲妈"类）。
6. 红线：禁用训诫句式（"你应当……""最高级的自律"）；不消费名人私生活；
   不制造对立；金句不喊口号（"要好好爱自己"式一律禁止）。
```

## 五、选题心理账户与开篇钩子片段

```
【选题心理账户与开篇钩子】（可选。先读取「选题卡」，它只用于选择切口和校验首屏，不替代安全转化 5 步法。）
1. 标题与首屏必须服务于同一个心理账户：读者想守住什么、最怕失去什么、为何迟迟不动。
2. 从「选题卡」的候选切口中选择一个最适合本篇六本账落点的方向；不可拼接多个焦虑点制造夸张冲突。
3. 开头 120–200 字优先使用选题卡中的具体场景、动作、物件或台词，让读者在前 3 屏知道自己被放进什么处境；不得开篇复述热点，或用“最近很多人”“数据证明”等未经核验的话术。
4. 可信度只能来自原始素材中保留的真实情感逻辑、透明脱敏和可核验公共事实；不可补造专家、数据、案例或时效。
5. 正文仍以故事、选择与代价推进；不要把文章写成口播节奏、营销方案或训诫文。文末只保留【本篇防撞车参数】规定的一种互动钩子。
```

## 六、压缩工作量时的指令

```
【本次为精简任务】现有稿约 X 字，需要压到「字数区间」字。
请遵循"砍铺陈、留刀子"原则：
- 砍掉：重复的铺垫、过渡性自述（"我想…""我建议…"）、重复表意的句群
- 一字不动地保留：核心比喻、核心台词、情绪重音的细节、
  "如果是你会怎么选"的各条选择及代价、结尾洞察
- 严禁为凑字数加水词；如需增字，只增加能强化人物或情绪的具体细节
改完后必须用脚本实测字数，并报告两个口径。
```
