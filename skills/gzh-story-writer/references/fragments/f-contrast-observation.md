# 体裁片段 F：对照观察（「隔山对照」等栏目）

> 仅当本篇投此类栏目时读。用法：把下面整段贴在主模板【写作要求】之后。
> 使用前提：两侧样本都必须有可核验来源；素材为公开视频时，同时附 `source-public-video.md` 的素材条款。

```
【体裁补充】这是对照观察型栏目。对照的是「同一个问题的两种处理方式」，
例如「一个家庭如何筹措房屋改造的钱」「一对夫妻如何分工做饭」。
不排名，不说「谁更好」，不把任何一侧写成反面教材。

【对照结构】
1. 共同的问题：先用一句话说清两侧面对的是同一个问题（如「老屋漏雨怎么办」）。
2. 样本 A：用场景和事实写清这一侧的做法、条件与代价。
3. 样本 B：同样的结构写另一侧。条件必须对等，不能只写一侧的优点。
4. 条件对照：列出影响做法的客观条件（气候、收入来源、材料可得性、家庭结构），
   解释为什么两种做法都是合理的。
5. 读者的位置：引出一个读者自己的选择或经历，但不替读者下结论。
6. 收束：一个开放的问题，或一个有代价感的判断。

【对照禁忌】
- 不写「他们很落后」「我们更先进」等价值排序。
- 不用「别人」「他们」之类的集体代称来概括整个国家或地区。
- 不把两侧的差异归因于「素质」「观念落后」等无法核实的原因。
- 两侧的字数尽量对等，避免一侧篇幅明显更长造成倾向。

【互动发问】优先使用开放式情境发问（不替读者预设选项），例如「面对这两种做法，你更习惯哪一种？」

【结构层】信息释放顺序与段落节拍按 references/hook-craft.md 执行（欠债账本、节拍器破坏；
本体裁天然双线，对应 T4 双线式拓扑，不另选号）。
```
