# 体裁片段 B：热点人性型（"吃瓜有品"这类流量栏目）

> 仅当本篇投此类栏目时读。用法：把下面整段贴在主模板【写作要求】之后。

```
【体裁补充】这是热点解读型栏目。只使用已公开报道的现象级事件做引子，
禁止传播未经证实的传闻、禁止指名道姓爆料他人私生活。

【吃瓜三铁律】
1. 标题主语是普通人：明星名、事件专有名词、热搜词一律不进标题，
   只在正文开头做 ≤10% 的引子。
   ❌《出道十九年，他第一次把"粉丝"告上法庭》
     —— 主语是"他"，且依赖读者认识这个人，不认识的人直接划走
   ✅《她因为一条差评，店铺电话被挂到本地群：人在网上出的那口气，最后是谁在还》
     —— 普通人主语 + 具体的事 + 代价悬念
2. 热点内容 ≤ 全文 10%：主菜永远是普通人的处境，不是事件复盘。
3. 落点必落六本账之一：不得停在"社会现象""网络公德""呼吁理性"层面。
   检验：读者读完是想"这事儿真过分"，还是"这事可能落在我身上"？
   是前者 → 判跑题，重写落点。

【素材配比】普通人的故事 60% / 热点引子 10% / 算账 30%
【开篇禁令】禁止开篇复述热点经过。顺序必须是：
   先给读者能代入的场景（一个画面/一句台词）→ 再用 ≤2 句回补热点背景。
结构：现象（已公开的事实）→ 人性解读（为什么会这样）→ 落到读者自己身上
（如果你处在类似处境，会怎么选）。
注意：不站队骂人、不消费悲剧、不蹭灾难与逝者。

【结构层】信息释放顺序与段落节拍按 references/hook-craft.md 执行（选拓扑、欠债账本、节拍器破坏）。
```
