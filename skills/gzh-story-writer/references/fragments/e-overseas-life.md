# 体裁片段 E：海外纪实生活流（「一屋一世界」「一日三餐」等栏目）

> 仅当本篇投此类栏目时读。用法：把下面整段贴在主模板【写作要求】之后。
> 使用前提：素材为公开视频时，同时附 `source-public-video.md` 的素材条款。

```
【体裁补充】这是海外纪实生活流。落点是「生活的逻辑」，不是「反差的标签」。
读者要看懂这种生活为什么是这样的：材料从哪来、钱花在哪、一天怎么安排、谁做什么。

【结构】
1. 场景开头（150 字内）：从视频中一个具体的动作、物件或声音开始。
   不解释背景，不做概括。
2. 过程正文：按视频中出现的顺序写，允许时间线推进，但不编造时间跨度。
   每一步写清三件事（如视频给出）：用了什么材料或工具，花了多少时间或钱，遇到了什么麻烦。
3. 观察段：用「我看到……」「视频里……」描述。解释为什么这样做，
   解释必须来自视频中的条件（天气、材料、家庭人数）或可核验的公开来源。
4. 反差段（如有）：反差必须是事实对比，例如「同一屋檐下，石膏吊顶与柴火灶并存」。
   禁止用「没想到」「居然」等惊讶词来制造反差。
5. 收束：一个具体的画面或一个不廉价的判断。不喊口号，不做道德评判。

【写作禁忌】
- 不编造对话与心理；视频中没有的，不写。
- 不用「原始」「落后」「土味」「贫穷」等词。
- 不把一个家庭的情况写成「当地人普遍……」。
- 数字只写视频中出现的或可核验的；未提及的写「视频中未说明」。

【互动钩子】本体裁的互动钩子优先使用「字母选项」或「一句话留言」，
题目要落在读者自己的生活上，例如「如果是你，最先会花钱改哪一处？」

【结构层】信息释放顺序与段落节拍按 references/hook-craft.md 执行（欠债账本、节拍器破坏；
拓扑以 T1 顺推为主，本体裁按视频时间线走时不强制轮换）。
```
