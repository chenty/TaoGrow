# 爆款骨架转化模块（viral-skeleton）

> **定位**：从"洞见"式爆款议论文中提炼、经"故事体"翻译后的通用爆款资产。
> 适用于本技能下所有账号，与各账号档案、`desensitize-5-steps.md` 并列叠加使用。
> **核心纪律一句话：借骨架、换血肉**——借的是选题、节奏、金句机制；换掉的是训诫体、掉书袋、口号收尾。
>
> 来源：洞见《道德经：不要介入他人因果，哪怕是家人》（2026-10-05）拆解；

---

## 一、五个通用杠杆（与体裁无关，所有栏目可用）

### 1. 选题公式：热词 / 争议 / 普遍困惑 + 落到读者处境
- 找目标读者群里正在吵、正在困惑的话题（人际边界、亲情定价、中年体面、友情的账……）。
- **不发明议题，给流行困惑一个"过来人的注脚"**——读者已经在纠结的事，才有点进来的动力。
- 必须落回读者的日常选择："换成你，怎么办"。

### 2. 标题公式：熟悉热词 + 亲密场景钩子
- 主句用一个读者熟悉的热词或处境短语。
- 副钩子拉到**最亲密的场景**："哪怕是家人""亲妈""三十年闺蜜"——把抽象话题拉到人人有感的距离。
- 制造反常识悬念：连最亲的人都要划线？点进去看看。

### 3. 结构节奏：快钩子、不铺陈、故事 + 落点循环
- 开头 3 屏内必须有具体场景或冲突（故事体：场景钩子；议论体：争议开场）。
- 每个情绪段 / 论点段 = **一个具体故事或细节 + 一句落点**，循环推进。
- 全文不出现超过一屏的抽象论述——议论只占落点那一句。

### 4. 故事冲击力：每个故事只留一个"扎人"的记忆点
- 留最痛的一个细节（极端后果、关键台词、体面崩塌的瞬间），细节密度 > 事件完整度。
- 读者记住的是那个细节，不是时间线。写故事时优先写"那天什么破了相"。

### 5. 金句纪律：每段一句可截图的话
- 金句 = 有代价感的判断或精准的比喻，放在**段尾**。
- 检验法：单独截出来发朋友圈，成立吗？不成立就不是金句，重写。
- **限频（防跨篇押韵）**："不是…是…""X靠的是A，Y靠的是B"类对仗判断句
  每篇**最多 1 句**——单看是金句，连读像同一个人在押韵。
  其余结论用大白话或一个具体动作收住。
- **加粗去同构**：不得每篇都是"转折钩子加粗 + 中段对仗金句加粗 + 结尾判断加粗"
  的三连节奏；金句可以不加粗，允许某篇全篇只有 0–1 处加粗。

## 二、借骨架换血肉：洞见骨架 → 故事体翻译对照表

| 洞见议论文做法 | 故事体版本（本技能标准） |
|---|---|
| 论点开场：引经典原文 | 场景钩子开场：一个具体画面 / 一句台词 |
| 论证：故事证明道理 | 叙事：故事本身就是全部，理只从事里长出来 |
| 训诫落点："你应当守住因果" | 选择落点："她怎么选的、代价是什么；换成你，怎么选" |
| 口号收尾："最高级的自律" | 代价收尾："她不是心狠，是算过账的人" |
| 掉书袋：道德经 / 庄子原文 | 人话手势："话说多了，人就远了"（概念不出场只出手势） |
| 站队 / 集体称谓 | 不评判任何人；不用"我们女人""姐妹们" |

> 翻译口诀：**论点变场景，道理变代价，训诫变选择，口号变账本。**

## 三、动笔前爆款骨架自检（写完初稿逐项过，非强制但建议）

1. **选题**：这篇踩中读者群体的高频处境或争议了吗？没有 → 换角度或回炉。
2. **钩子**：开头 3 屏内给出具体场景或冲突了吗？没有 → 把第一段改成一个画面。
3. **故事支撑**：每个情绪 / 论点段都有具体故事或细节吗？没有 → 补人物样本与细节，**不加议论**。
4. **金句**：全篇有一句能单独截图传播的话吗？没有 → 重写一句；有 → 检查是否落在"口号位"，是则打散或移到段尾。再查限频："不是…是…"类对仗句是否超过 1 句？加粗是否又是"钩子+中段+结尾"三连？是则删到 1 句以内、打散加粗位。
5. **标题**：含亲密场景钩子吗？（"哪怕是""三十年""亲妈"类）没有 → 补一个再交付。

## 四、红线（融入时守住，防止骨架带毒）

1. **不写训诫体**——"不要介入因果""成年人应当……"这类句式禁用，一律翻译成样本与代价。
2. **不消费名人私生活**——历史公案（鲁迅 / 曾国藩 / 陈垣）可引作公开案例；当代名人的家事不碰。
3. **不制造对立**——借争议开题可以，站队骂人不行。
4. **极端故事必须脱敏**——越戏剧化的素材越要过 5 步法；"劝闺蜜离婚""替弟还债"这类最易对号入座，四要素（职业+城市+特殊事件+与我的关系）凑齐就危险。
5. **金句不喊口号**——结尾禁用"要好好爱自己"式廉价句式；"守住本分就是成全"这类也要翻译成有代价感的判断。

## 五、与既有资产的分工

| 资产 | 分工 |
|---|---|
|  `accounts/<slug>.md` | 账号人设 / 栏目 / 禁忌（本次写什么） |
| `desensitize-5-steps.md` | 素材安全转化（能不能写、怎么写不伤人） |
| `prompt-template.md` | 提示词组装（动笔怎么提要求） |
| `enhancements.md` 第四节 | 爆款骨架增强片段（可直接贴进提示词） |
| `viral-skeleton.md`（本文件） | 爆款机制（怎么写得有人读、有人转） |

四者顺序使用：**档案定人设 → 5 步法定安全 → 骨架定爆点 → 模板定产出。**
