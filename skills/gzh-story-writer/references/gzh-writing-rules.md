# 公众号文章共性规律（写作自检清单）

写任何公众号文章时逐条对照，交付前复核。

1. **具体人物承载抽象话题**：人物身份＋具体场景＋目标或困境。不直接讲大话题。
2. **认知反差制造点击欲**：标题=人物＋地点/行动＋意外结果。反差要有事实支撑，不把个人体验扩大成对群体判断。
3. **开头三段**：P1 画面/矛盾抓注意力 → P2 人物身份与场景 → P3 抛核心问题。公式：异常细节＋人物处境＋待解悬念。
4. **正文小节点推动**：起因→尝试→遇阻→变化→结果→引出思考；每隔几段有新障碍/新发现/新变化。
5. **情绪价值＋实际信息**：写清「遇到什么、为何意外、读者能带走什么」（价格/地点/方法/规则），不空写情绪。
6. **细节与对话增现场感**：动作、数字、引语、场景细节。区分真实引语/转述/示例，不编造对话。
7. **作者适度点评不抢戏**：关键节点简短评论或幽默；不连续评价人物，不把猜测写成事实。
8. **结尾引导讨论**：具体场景＋两种选择＋邀请分享经历（如「语言不通时，你更习惯用翻译软件还是请路人帮忙？」），不用空泛「你怎么看」。
9. **素材与传播判断注明边界**：事实、当事人说法、网友观点、作者推测分开；引用标注来源；图片确认授权。无数据时只说「可能的传播原因」，不断言爆火原因。

一句话：用具体人物进入真实场景，用反差和问题吸引阅读，用连续细节推动故事，让读者既有情绪共鸣也带走有用信息。
