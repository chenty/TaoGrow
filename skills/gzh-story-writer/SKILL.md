# 公众号"人间故事"文章创作器

## 用途

把真实素材（口述 / 身边故事 / 读者投稿）写成可直接发布的公众号文章，**并强制完成隐私脱敏**——这是本技能与"帮我写篇文章"的根本区别。一套流程服务任意数量的公众号，各号参数独立配置。

**何时不用**：纯营销文案、产品软文、活动通知；生成图片/视频；明确要编造的虚构故事（本技能前提是"素材来自真实"）。

---

## 工作流

### 步骤 0：确认账号（必须最先做）

只读 `references/account-index.md`（含所有账号的人设/读者/字数一行摘要）。

| 情况 | 动作 |
|---|---|
| 账号已存在 | 读 `references/accounts/<slug>.md`，向用户确认一次"这次用 X 号，Y 人设，Z 字数"即可开工 |
| 用户未指明账号 | 把索引里的账号列给用户选，**不要自己猜** |
| 账号不存在 | 读 `references/account-template.md` 采集 10 项参数建档，在 `references/accounts/` 新建文件并在索引追加一行 |

> ⚠️ **只读选中账号那一个文件**。其余账号档案不要读——那是纯浪费。

**10 项参数**：账号名 / 人格昵称 / 人设 / 调性关键词 / 读者画像 / 内容主线与常设栏目 / 字数区间 / 禁忌＋固定引导语 / 冷启动约束 / 口吻分版归属（定义见 `account-template.md`）。
**配图任务**：视觉小节若指向细则文件，出图前必须先读；各账号 IP 锚点图已内置于技能 `assets/anchors/<slug>/` 目录。

### 步骤 1：确认素材与体裁

**先判断素材类型**（决定走哪条处理路径）：

| 素材类型 | 处理路径 | 关键约束 |
|---|---|---|
| 口述、聊天记录、身边熟人故事、读者投稿 | `desensitize-5-steps.md` 完整 5 步法 | 可以改地点、人物、数字（为了脱敏） |
| 公开视频（如 YouTube）中的陌生人 | `source-public-video.md` 替代流程 | **不改**地点、人物、数字；核实来源与事实；处理肖像与版权 |

**再判断脱敏红线**（详解见 `references/desensitize-5-steps.md`）：

- 涉及**近期熟人事件**（发生不足 6 个月）→ **提示用户冷却，不要直接写**
- 涉及违法犯罪、未成年人、可查证具体信息 → **拒绝并说明原因**
- **机审合规与词密度控制（重要）**：机器按词的“分布密度”打分。涉及就业、收入、健康、纠纷题材时，同类敏感词全文累计 ≤3 次，单个词 ≤2 次；拆开相邻敏感组合（如失业+女性）；避开金融/纠纷联想词（流水/补偿金/offer改口语转述）。详见 `desensitize-5-steps.md` 第七节。

**原型查重**（素材疑似网络段子/爽文原型时必做）：情节骨架高度戏剧化（如"被亏待→出走→逆袭→对方悔恨"）或你直觉"这梗见过" → WebSearch 同题词 2–3 轮核查。
**文字原创 ≠ 安全**：情节撞车不构成侵权，但会伤"真实故事"人设——读者大概率刷到过同款爽文。
确认同题则**错开爽文节拍**：去具体金额（"一笔整钱"不写数字）／不把对方写成恶人／砍掉暴富逆袭爽点换更小的真实动作／不给"恶人悔恨崩溃"的反转尾巴。

**定栏目与字数**：用户指定优先，否则用账号默认。按栏目取体裁片段（A `a-real-story` / B `b-hot-topic` / C `c-money-choice` / D `d-reader-letter` / E `e-overseas-life` / F `f-contrast-observation`，见 `references/fragments/`；公开视频素材通常对应 E 或 F）。

**特殊体例**：开号宣言、周年文、号主自述等"非栏目文"套用 **A 体裁骨架**（场景钩子 → 身份交代 → 为什么做这件事 → 规矩/承诺 → 收束），落点仍是"你处在这个处境会怎么想"，叙事人＝号主本人；自我披露同样受"暴露处境类型、不暴露可指认细节"约束。

### 步骤 1.4：选题心理账户与开篇钩子（可选）

新号冷启动、素材流于琐碎流水账、同一素材多角度、或要增强立意与标题点击时，读 `psychological-account-topic-hooks.md`：
- **选题升维（可选杠杆）**：素材平淡时调用【顶尖视角升维提问法】，从个人成长与底层交换契约（商业/人情账）升维思考，确立主理人势能，再降维为读者可代入的体感；
- **落地切口**：写心理账户（空缺标待验证，不臆测）→ 用时效性/永恒痛点/认知颠覆/情绪杠杆生成 ≥3 切口（各标落点、首屏场景、证据边界、风险）→ 选定 120–200 字首屏草案。只决定"从哪开门"，**不能绕过**脱敏、冷却期、热点配比、防撞车。

### 步骤 1.5：落点校验（动笔前必过，答不出就不动笔）

1. **落点是"六本账"哪一本？**（情感/婚姻/人情/金钱/自我/选择，定义见 `account-template.md`）
   答不出 → 换角度。落到"社会现象""网络公德""正能量""值得深思" → **判为跑题，重写落点**
2. **代入检验**：45 岁读者会在自己身上对号入座吗？读者是旁观者（"这事儿真过分"）→ 不合格；是当事人（"这事可能落在我身上"）→ 合格
3. **素材配比**（热点类栏目）：普通人故事 60% / 热点引子 10% / 算账 30%——热点只是门牌，进门后必须是读者的处境

### 步骤 1.6：跨篇防撞车（动笔前必过）

**先跑脚本**（本脚本仅提供 Node 版；环境无 node 时按下方 6 条参数人工核对）：

```bash
node scripts/ledger.js check <账号名称>     # 无 node 时用 python3 scripts/ledger.py
node scripts/ledger.js suggest <账号名称>
```

对照输出定下 **5 个参数**，违反禁用项绝不动笔：

> ⚠️ **步骤 1.6 必读本技能 `references/hook-craft.md`**：本表只管表层指纹，
> 深层骨架（拓扑 T1–T6 选拓扑、欠债账本、节拍器破坏）在那份参考件里，两层都过才能动笔。
> 定参数时把拓扑编号写入第 5 项，交付登记时 --structure 记同号。

| # | 参数 | 硬规则 |
|---|---|---|
| 1 | 人物称呼 | **去老 X 化**；近 5 篇用过的称呼不得复用（同名不同人也不行）；优先身份代称 |
| 2 | 选择数量 | 2–5 种，与上一篇强制不同；**严禁连续两篇 5 选项** |
| 3 | 结尾钩子形态 | 与上一篇必须不同，五形态轮换（见下）；每周④⑤至少 1 次 |
| 4 | 结构骨架 | 最近连续用过的换掉（纯对话体/时间线/一封回信/第一人称/清单反转） |
| 5 | 金句与加粗 | 对仗判断句每篇**最多 1 句**；加粗位置漂移，允许某篇 0–1 处 |

> 完整规则与判例见 `cross-post-rules.md`；首写新账号时脚本自动创建 `ledger_<账号名称>.json`。

**结尾互动钩子五形态**（每篇必带，与上篇不同）：① 数字选项　② AB 二选一　③ 字母选项　④ 开放式填空　⑤ 一句话留言。各形态示范见 `references/cross-post-rules.md` 第五节。

❌ 禁止只写"欢迎留言讨论""你怎么看？"——无抓手，等于放弃互动率。
**为什么**：留言数→互动率→推荐流，新号阶段唯一零成本的流量杠杆。

### 步骤 2：生成初稿

读 `references/prompt-template.md`（含主模板+占位符），附所选体裁片段，组装并生成。**必须走完"安全转化 5 步法"，不完成不动笔。** 公开视频素材以模板的【素材类型条款】为准，走 `source-public-video.md` 第八节的替代流程。

可选增强（组装时附加片段）：
- **爆款骨架** → `enhancements.md` 第四节 + `viral-skeleton.md` 翻译表。只借选题公式、标题钩子、故事冲击、金句纪律、结构节奏；换掉训诫体、掉书袋、口号收尾
- **选题心理账户** → 步骤 1.4 的选题卡 + `enhancements.md` 第五节（选题卡不进正文）

### 步骤 3：字数实测（不可省略）

**不要相信模型自报的字数。**

```bash
node scripts/count_cjk.js <文件路径> --body-start <首行> --body-end <末行>
python3 scripts/count_cjk.py <文件路径> --body-start <首行> --body-end <末行>
```

- 先探 `python3 --version` / `node --version`；两者皆可用时优先 `count_cjk.py`（双口径逻辑与 JS 版完全一致）
- 输出"纯汉字数"与"含标点数"**两个口径都要**落在用户区间内，只满足一个不算过
- 需排除的段落（脱敏说明、标题、引导语）用 `--exclude 行号,行号`
- ⚠️ **行号必须当场复核**：首末行号常因增删漂移，用错一个就少算/多算（实测曾把末行写小 3 行，少算近 50 字）。改完稿用 Grep 查起止标记确认再跑
- 超区间 → 按下方"字数调整原则"改，**不要靠加水词凑数**（初稿偏短是常态：加人物样本/具体细节，不加议论与过渡）

### 步骤 4：交付

1. 写入 `<账号名称>_<题材>_<字数区间>.md`；**台账回填（不可遗漏）**：
   ```bash
   node scripts/ledger.js log <账号名称> --title "标题" --hook "② AB 二选一" \
     --choices 3 --opening "开头前1-2句" --opening-style "物件开场" \
     --names "表姐夫,师傅" --structure "时间线推进" --bold-count 2 \
     --antithesis-count 1 --words 1180 --tags "#中年女人的钱,#婆婆的账"
   ```
2. 文末按顺序：互动钩子 → 固定引导语（若账号有）→ **话题标签一行** → 5 步法自检
   标签行：1 主 + 1–2 副（≤3），空格分隔，紧接引导语独立成行；**属正文**，与正文、引导语连成一块，一次复制即完整
3. **提醒用户**：自检发布前删掉；标签行随正文带走
4. 对照 `references/pre-publish-checklist.md` 过一遍自检项（核心 8 项 + 防批量 5 项必检；公开视频素材追加 4 项）；运行 `python3 scripts/check_density.py <成稿路径>` 进行敏感词密度与机审避险检测
5. 附**摘要**（≤120 字、含目标关键词）＋**配图方案**（插在哪段后／画面／尺寸；画风照账号视觉小节，人物不画正脸）
6. 封面出**两件套**（2.35:1 大图 ＋ 1:1 缩略图 ＋ 横排合并），字号交脚本算，别手调：
   `python3 scripts/make_cover.py --art <底图> --column <栏目名> --title <4-8字> --subtitle <一句> --outdir out/`
   像素扫描求画面上沿＋二分求字号，压图即报错；栏目名不带编号。封面字体**默认龙藏体
   Long Cang**（连笔松弛手写风）：账号档案或用户另行指定时才用 `--font-serif`（宋体）/
   `--font-sans`（黑体）/`--font <路径>` 覆盖；脚本安全区报告会打印实际字体，
   出现回退警告时先跑 `bash scripts/setup.sh --install-font`，不要带警告交付。
   **两个扫描/裁切陷阱**（改底图后必检）：
   - 底图右侧有深色主体（人物头发）时，默认扫描区间会把画面上沿误判为 y=0，
     导致最小字号都放不下 → 缩窄 `--scan-x0/--scan-x1` 到左侧纯留白区，走 fallback。
   - 底图人物在右侧时，缩略图默认取最左 768px 会把主体裁掉 →
     加 `--thumb-crop-x 1.0` 改为取右侧；0=最左、1=最右，按主体位置调。
   - 极淡水彩底纹也可能被误判成画面上沿压小字号 → 降低 `--scan-threshold`、
     加大 `--scan-run`，并**目视确认**文字未压任何画面元素。
7. 确认目标关键词已埋入标题/摘要/首段（见 `references/search-traffic.md`）；选词理由与埋入位置写复盘区
8. 提醒发布时间：40+ 女性读者推荐 **20:00–22:00** 或 **7:00–8:00**；下午是全天低谷

## 全篇硬规则

### 文风（所有账号通用）

第一人称；口语化、有呼吸感、有具体细节。**不评判人物**（不骂任何一方，不预设对错）。**不喊口号**（禁用"女人要好好爱自己"式廉价句式）。**不用集体称谓**（禁用"我们女人""姐妹们"）。不制造焦虑、不煽动性别/地域对立。段落要短（手机一屏 1–2 段）。

### 字数调整：砍铺陈、留刀子

- **砍**：重复铺垫、过渡性自述（"我想…""我建议…"）、重复表意的句群
- **留（一字不动）**：核心比喻、核心台词、情绪重音细节、各条选择及各自代价、结尾洞察
- **严禁**为凑字数加水词；如需增字，只加能强化人物或情绪的具体细节

### 标点与引号（去 AI 味的硬指标）

**逢词就加引号**是 AI 中文的高频指纹——"闺女""租""亲自到场"这类表强调/反讽/特殊称谓/自造词的引号，真人手写极少用；一篇堆七八处就是机器味。

- **引号只留给真正的对话引语**（人物亲口说的一整句话）
- 表强调/反讽/特殊称谓/自造词**一律不加**：✅ 租个孩子陪爹妈　❌ "租"个孩子
- 密度：正文成对引号 **≤1–2 处**（含对话）；标题最多 1 处，且必须是去掉就会误读的反讽钩子
- **一律中文弯引号 “”**，禁止英文直引号 `"`（U+0022）
- 顺带节制：感叹号能不用就不用，省略号不连用，破折号与加粗不堆
- 例外：引导语里的固定口令（如回"来信"、回"树洞"）是品牌资产，**保留原样**

## 常见失误

1. **没实测字数就报数** —— 自报普遍不准，必用脚本
2. **只满足一个口径** —— 用户说"900–1200 字"时，纯汉字与含标点都要落在区间内
3. **把"改名字"当成脱敏** —— 改名只是起点，关键是去掉"四要素凑齐"的可识别性
4. **写到结尾开始说教** —— 洞察 ≠ 训话，判断要平视、要带代价感
5. **文字原创就当安全** —— 网络流传原型先 WebSearch 查重，错开爽文节拍
6. **落点停在现象层** —— "值得深思"就是跑题，先过 1.5 校验
7. **只防篇内、不防篇间** —— 单篇都合格但连读像同一模子。动笔前必过 1.6，交付后必登记
8. **发布后不看系统搜索词** —— 弹词是免费的选词指南：强相关就下一篇围绕它选题；弹词奇怪就是核心词密度不够
9. **公开视频素材照搬熟人路径** —— 改地点、合并人物会让真实感失效。公开素材必须走 `source-public-video.md`，只做隐私处理，不改事实
10. **为海外素材补编细节** —— 视频里没有的对话、心理、数字一律不写；不能核实的背景宁可不写，也不要写成「当地人普遍……」
11. **单看词语合规，忽略敏感词密度** —— 机器按词密度打分。就业/涉钱负面词扎堆（单篇超3次）、存在敏感词相邻组合（如“失业妇女”）会直接触发平台警告。动笔前换域，交稿前必须运行 `scripts/check_density.py` 自检并稀释
