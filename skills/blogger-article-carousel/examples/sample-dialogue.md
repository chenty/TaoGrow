# 示例对话：把一篇长文做成小红书轮播

> 示例演示分轮沟通。真实任务应先读取用户提供的文章，不要求用户重复输入。

## 第 1 轮：确认传播任务

**用户**：把这篇关于普通人做副业定位的文章做成系列卡，先问我几轮。

**Agent**：我先确认传播任务：
1. 平台按小红书 3:4 竖版可以吗？
2. 主要给刚开始做副业/自媒体的普通上班族看，还是已有账号的创作者？
3. 读者看完最希望做什么：理解观点、收藏行动方法，还是留言讨论？
不确定的可以回“你推荐”。

**用户**：小红书，普通上班族，重点让人收藏，不要导流。

## 第 2 轮：确认文章理解与升维角度

**Agent**：我读到的核心主张是：普通人不必先找到终身事业；先定一个眼前可执行的目标，在行动里积累能力和见识，再逐年调整方向。文章还强调现金流和试错空间会影响一个人能长期投入多久。

建议 8 张，但这只是按本文内容推出来的方案，不是固定模板：封面 → 普通人的现实起点 → 为什么终身目标会让人更难开始 → 一年目标怎么定 → 行动如何带来能力和选择 → 长期主义需要什么条件 → “常立志”的复盘循环 → 可收藏的行动清单。

如果希望建立个人 IP，还可以把“副业方向”这个具体问题连到能力成长与经营底座（现金流、试错空间）；这条桥有文章依据，但是否加重由你决定。你想停留在实用层面，还是加上成长/经营视角？另外，是否要保留“常立志，不立长志”并弱化“大俗人”的自嘲感？

**用户**：加成长和经营视角；保留“常立志”，但“大俗人”别写得像贬低读者，要讲清楚不是认输。

**Agent**：收到。我会把“大俗人”解释为认清现实起点，而不是评价个人价值；把成长与经营作为解释层，但每一层都回到文章已有论据，不额外编造成功案例或商业结论。

## 第 3 轮：确认视觉方向

**Agent**：视觉方向给你三个选择：
- A 温暖手绘编辑风：亲切、留白多；
- B 清爽步骤图解：更理性、适合收藏；
- C 强标题杂志风：封面更醒目、内页更克制。

你有品牌色或固定字体吗？

**用户**：选A，暖绿和橙色，没有品牌字。

## 第 4 轮：先审文案

**Agent**：下面先审每页文字，不急着批量出图：

1. **封面**｜普通人做副业，别急着找一辈子的方向｜先定一年，再边做边迭代。
2. **现实起点**｜看不远不是人生判决｜见识、经验、引导和现金流都会限制选择。
3. **拆掉门槛**｜别把终身事业当入场券｜先把今年能做好的事做好。
4. **一年目标**｜今年能完成哪件具体的事？｜拆成每月行动，年末再看结果。
5. **迭代机制**｜做成一件事，能力与见识就增长｜更多能力带来更多选择。
6. **长期底座**｜长期主义需要能力托底｜现金流、技能和试错空间影响可持续性。
7. **常立志**｜定目标、行动、复盘、调整｜不是摇摆，是用新经验校准方向。
8. **行动清单**｜从今天的一步开始｜赚钱、长见识、练能力，逐件做出来。

请逐页指出要改的地方；确认后再进入提示词委托与视觉样张。

## 第 5 轮：委托 handdraw-style-prompter 生成提示词并制作样张

**用户**：文案通过，封面再突出“先定一年”。

**Agent**：已更新封面标题。接下来我将第 1 张封面的获批文案与系列视觉 brief（3:4 竖版、温暖手绘编辑风、暖绿与橙色主题、留白层级）交给依赖技能 `handdraw-style-prompter` 生成封面出图提示词，并先出 1 张封面样张供你确认。样张通过后，我再逐张调用 `handdraw-style-prompter` 生成第 2–8 张的出图提示词并完成整套卡片；最后逐张校对文字、比例和页序，交付独立图片、PDF 预览和 ZIP。
