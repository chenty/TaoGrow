# 文章拆解、多维解释与故事线

## 先回答五个问题

阅读文章后，内部整理以下要点；只把对成品有帮助的部分展示给用户：

1. **是什么**：作者最想让读者相信或理解什么？用一句话表达。
2. **为什么**：读者原有的困惑、误区、限制条件或矛盾是什么？
3. **凭什么**：文章给出的推理、事实、经验、案例或类比是什么？区分作者观点、可核事实和个人经历。
4. **怎么做**：文章是否给出方法、步骤、判断框架或行动建议？没有就不补造。
5. **边界与下一步**：该观点适用于什么情况？有哪些条件不能省略？读者看完能做哪一步？文章没有行动建议时，可自然收束，不强加 CTA。

## 建立“观点—论证—行动”地图

按文章实际内容提取相关单元，而不是照抄段落顺序或强行补齐栏目：

- 核心主张或观察（如果有）；
- 读者当前的难题、常见误解或事件起点；
- 造成问题的原因、约束或关键矛盾；
- 文章的转折、判断或反直觉观点；
- 支撑论点的案例、经验或证据；
- 方法、步骤、关系或可执行建议（如果文章提供）；
- 适用边界、风险或现实条件（如果相关）；
- 作者想留给读者的结论、问题或余韵。

这些是候选内容，不是必填清单。复杂文章可从互补角度组织卡片，例如现实背景、认知机制、行动方法、成长变化或资源边界；不要求凑够固定数量。所有角度必须能从原文或用户补充的信息中得到支撑。

## 爆款传播与个人 IP 升维（可选）

当用户希望提高传播力、建立个人 IP，或明确要求把具体问题连接到个人成长/商业经营层面时，可采用资深内容策略师与个人 IP 顾问的思考视角。这个视角是**选题分析工具**，不是每篇都要执行的拔高公式，也不保证爆款。

按文章证据尝试建立这条逻辑桥：

1. **具体问题**：读者眼前究竟遇到什么可描述的问题？先讲实，不从抽象口号开始。
2. **共同处境与情绪**：背后有哪些现实限制、矛盾、焦虑、取舍或期待？用原文和用户补充验证，不假装知道所有读者的感受。
3. **更高一层的解释**：文章是否支持连接到个人成长（能力、选择、责任、学习、长期积累等），或商业经营（现金流、用户价值、定位、产品、运营、系统、可持续性等）？选真正相关的一层，不要求两者都讲。
4. **作者的独特判断**：作者基于什么经历、价值观或推理形成与众不同的立场？可以帮助识别可持续的个人 IP 观点，但不得编造资历、成功经历或“独家方法”。
5. **回到具体价值**：把高层判断落回读者能理解、能判断或能尝试的一步。让读者感到被准确理解，也能看见作者的推理，而不是被情绪操控。

可作为内部分析路径：

`具体困扰 → 共同处境/情绪 → 原文支持的成长或经营判断 → 作者独特立场 → 读者可采取的下一步`

**升维质量检查：**去掉“个人成长”“商业经营”等大词后，逻辑桥还成立吗？若不成立，说明可能只是在贴标签；回到具体论据，或询问作者是否愿意补充经历、数据、经营案例。共鸣来自准确描述处境和有用解释，不靠夸张、羞辱、制造对立、虚假共情或保证读者一定认同。

若用户不想做 IP 升维，或文章证据不足，就停留在具体主题层面。不要把所有生活问题都硬转成商业课，也不要把所有经营问题都包装成励志成长。

## 可选故事线：仅作启发，不是固定页序

不同文章可以是观点辩论、经验随笔、教程、故事、案例复盘、概念解释或混合结构。不要把它们都套进同一条“封面—问题—方法—案例—总结”路线。先判断文章的论证形态，再从以下示例中借用、重排、合并或完全不用：

- **观点型**：主张、疑问、论据、推理、适用范围；不要求都有案例或行动页。
- **方法型**：目标、条件、关键操作、判断标准、卡点；文章没写到的步骤不要补齐。
- **案例/经历型**：事件、选择、转折、结果、反思、可迁移与不可照搬之处；不把个人经历泛化为普遍规律。
- **知识解释型**：概念、组成、关系、机制、例子或边界；按理解需要取舍。
- **随笔/观察型**：一个细节或现象、作者的感受、形成的判断、留给读者的余味；不强行变成步骤指南。
- **混合型**：先标出文章各段的功能，再设计本篇独有的阅读路径。

## 每张卡的编写卡

仅填写对当前文章有用的字段；可以增删字段，不要求每页都一样：

- 本页在整组中的作用/要回答的问题；
- 主旨或必要信息；
- 标题与实际可见文案；
- 原文依据；
- 可选例子、引用、边界或限定条件；
- 可选的成长/经营升维及其逻辑桥；
- 视觉表达与前后页关系。

## 页数与阅读节奏

页数由文章中独立内容单元和阅读节奏决定；常见页数区间只是估算，不是任务配额。一个集中观点可以很短，论证多的文章可以更长。不要按字数均分；若两页重复就合并，若一个重要推理跳步就拆开。
