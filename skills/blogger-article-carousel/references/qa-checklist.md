# 成品校对清单

在把卡片称为“完成”之前，逐项检查；无法检查的项目明确说明。

## 内容准确性

- [ ] 整组准确表达文章核心主张，不只摘句不讲逻辑。
- [ ] 每页有不同的解释任务；没有同义反复或缺失的关键过渡。
- [ ] 原文的重要条件、语气、例外和现实限制没有被删掉。
- [ ] 没有添加原文没有支持的数字、日期、研究、案例、承诺或因果结论。
- [ ] 引号内确实是逐字引用；概括句没有伪装成原话。
- [ ] 标题钩子没有夸大文章结论或制造虚假冲突。
- [ ] 若启用个人 IP / 爆款升维，具体问题到成长/经营判断之间有原文支撑的逻辑桥；没有强行拔高、虚假共鸣或爆款保证。

## 文案可读性

- [ ] 每页只有一个主要观点，缩略到手机预览仍能识别标题。
- [ ] 句子简短，避免堆满小字；关键名词和行动动词清楚。
- [ ] 术语已解释，代词、页间指代和时间顺序明确。
- [ ] CTA 与文章相关，不强行营销或导流。

## 视觉一致性

- [ ] 每张画幅、边距、主色、字级、线条和纸感一致。
- [ ] 版式随内容变化但不跳出同一视觉系统。
- [ ] 角色/物品/符号在跨页重复时保持一致。
- [ ] 没有模糊、裁切、遮挡、低对比、意外重影或不自然留白。
- [ ] 没有未请求的 Logo、水印、品牌、日期、二维码或外部链接。

## handdraw-style-prompter 委托

- [ ] 最终图像提示词由 `handdraw-style-prompter` 生成，不是由本 Skill 自行撰写/改写。
- [ ] 每张卡单独委托，提示词与获批文案、视觉 brief 一致。
- [ ] 若依赖 Skill 不可用，已暂停出图提示词并向用户说明，没有绕过依赖。

## 图片文字与文件

- [ ] 逐张核对标题、正文、数字、标点、符号、页码；特别检查图像模型生成的小字。
- [ ] 没有乱码、错字、漏字、重复句或凭空出现的微型标签。
- [ ] 一页一个文件，文件顺序明确，比例与尺寸一致。
- [ ] PDF/ZIP（若提供）页数与卡片数一致，解压后文件齐全。
- [ ] 对不可避免的生成瑕疵，明确告知用户并提供修正建议。

## 隐私与发布

- [ ] 没有未经同意保存整篇原文、上传文章或访问社交账号。
- [ ] 生成草稿不等于发布；任何外部发布都需用户明确确认。
