# 公众号高共鸣选题与聊天体写作 Skill

## 文件结构
```text
wechat-high-resonance-chat-writing/
├── SKILL.md
├── README.md
└── references/
    ├── article-review-checklist.md
    ├── topic-planning-template.md
    └── variation-checklist.md
```

## 安装
将整个 `wechat-high-resonance-chat-writing` 文件夹放入支持 Agent Skills 的工具所使用的 skills 目录中。不要只复制 `SKILL.md`，因为参考模板也属于技能配套资源。

不同平台的技能目录和启用方式可能不同；安装后确认工具能够识别 `SKILL.md` 的 YAML frontmatter 中的 `name` 与 `description`。

## 快速调用
- “调用公众号聊天体写作 Skill，帮我策划 10 个关于中年职场转型的选题。”
- “用这个 Skill 分析这篇文章的选题、标题和开头。”
- “按聊天体写作，围绕‘人越忙越容易忽略真正重要的事’写一篇公众号文章。”
- “检查这篇稿子是否有 AI 腔，并在保留事实和观点的前提下改写。”

## 设计原则
先判断选题，再写文章；素材不足时询问关键事实，不虚构作者经历；结构按主题选择，不固定套模板；连续创作时主动检查表达重复；对数据、引语、新闻和专业判断保持事实边界。
