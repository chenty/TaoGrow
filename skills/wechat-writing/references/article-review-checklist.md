# 公众号文章审稿清单

此清单用于写作完成后的内部质检，不必机械展示给读者。

## 选题
- [ ] 目标读者是否明确？
- [ ] 是否对应真实生活处境？
- [ ] 是否有具体矛盾，而不只是宽泛主题？
- [ ] 核心判断是否清楚？
- [ ] 是否有足够素材支撑？

## 标题与开头
- [ ] 标题是否具体、有吸引力且不夸大？
- [ ] 标题是否兑现于正文？
- [ ] 第一段是否迅速建立注意力？
- [ ] 前三段是否完成关联和阅读期待？
- [ ] 是否避免空泛背景铺垫？

## 正文
- [ ] 是否有真实场景、经历或可靠案例？
- [ ] 观点是否有解释和支撑？
- [ ] 语言是否自然、松弛？
- [ ] 长短句是否有变化？
- [ ] 是否存在重复、注水、过度总结？
- [ ] 是否像在交流，而不是讲课？

## 真实性
- [ ] 是否把事实、观点、推断和预测区分开？
- [ ] 数据、引语和事件是否有来源？
- [ ] 是否把虚构场景误写成真实经历？
- [ ] 是否有夸大承诺或误导性表达？

## 结尾与差异化
- [ ] 结尾是否自然？
- [ ] 互动问题是否具体？
- [ ] 是否避免套路化升华？
- [ ] 是否与近期文章在开头、结构、案例或结尾上有所变化？
